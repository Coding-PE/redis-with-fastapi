# Redis 공통 키 명령어 모음

> 강의노트 Ch.03 — Redis 기본 자료형과 명령어 / 공통 키 명령어

---

## 1. TYPE — 자료형 확인

```bash
127.0.0.1:6379> SET user:1:name "Kim"
127.0.0.1:6379> TYPE user:1:name
# string

127.0.0.1:6379> LPUSH mylist "a" "b"
127.0.0.1:6379> TYPE mylist
# list

127.0.0.1:6379> HSET user:1 name "Kim"
127.0.0.1:6379> TYPE user:1
# hash

127.0.0.1:6379> SADD myset "a" "b"
127.0.0.1:6379> TYPE myset
# set

127.0.0.1:6379> ZADD myzset 100 "Kim"
127.0.0.1:6379> TYPE myzset
# zset
```

> 💡 Sorted Set의 TYPE 반환값은 `sortedset`이 아니라 `zset`입니다.

---

## 2. RENAME — 키 이름 변경

```bash
127.0.0.1:6379> SET user:1:name "Kim"
127.0.0.1:6379> RENAME user:1:name user:1:username
# OK

127.0.0.1:6379> GET user:1:username
# "Kim"

127.0.0.1:6379> GET user:1:name
# (nil)   ← 기존 키는 사라짐
```

> ⚠️ `newkey`가 이미 존재하면 기존 키를 **삭제 후 덮어씁니다.**

## 3. OBJECT ENCODING — 내부 인코딩 확인

```bash
# String
127.0.0.1:6379> SET counter 100
127.0.0.1:6379> OBJECT ENCODING counter
# "int"   ← 정수는 int 인코딩

127.0.0.1:6379> SET greeting "hello"
127.0.0.1:6379> OBJECT ENCODING greeting
# "embstr"   ← 짧은 문자열은 embstr 인코딩

127.0.0.1:6379> SET longstr "아주 긴 문자열입니다. 일정 크기를 넘으면 raw로 전환됩니다. 넘어야 합니다."
127.0.0.1:6379> OBJECT ENCODING longstr
# "raw"   ← 긴 문자열은 raw 인코딩

# Hash
127.0.0.1:6379> HSET user:1 name "Kim" age "30"
127.0.0.1:6379> OBJECT ENCODING user:1
# "listpack"   ← 필드 수 적을 때

# List
127.0.0.1:6379> RPUSH mylist "a" "b" "c"
127.0.0.1:6379> OBJECT ENCODING mylist
# "quicklist"   ← List는 항상 quicklist

# Set
127.0.0.1:6379> SADD numbers 1 2 3
127.0.0.1:6379> OBJECT ENCODING numbers
# "intset"   ← 정수만 있을 때

127.0.0.1:6379> SADD numbers "hello"
127.0.0.1:6379> OBJECT ENCODING numbers
# "hashtable"   ← 문자열 추가 시 전환

# Sorted Set
127.0.0.1:6379> ZADD myzset 100 "Kim" 200 "Lee"
127.0.0.1:6379> OBJECT ENCODING myzset
# "listpack"   ← 멤버 수 적을 때
```

## 4. TTL / EXPIRE — 키 만료 시간 관리

```bash
# EXPIRE — 만료 시간 설정 (초 단위)
127.0.0.1:6379> SET session:user1 "abc123"
127.0.0.1:6379> EXPIRE session:user1 60
# (integer) 1

# TTL — 남은 만료 시간 확인 (초 단위)
127.0.0.1:6379> TTL session:user1
# (integer) 57

# PEXPIRE — 만료 시간 설정 (밀리초 단위)
127.0.0.1:6379> PEXPIRE session:user1 60000
# (integer) 1

# PTTL — 남은 만료 시간 확인 (밀리초 단위)
127.0.0.1:6379> PTTL session:user1
# (integer) 57842

# EXPIREAT — 특정 Unix timestamp에 만료
127.0.0.1:6379> EXPIREAT event:newyear 1735689600
# (integer) 1

# PERSIST — 만료 시간 제거 (영구 보관)
127.0.0.1:6379> PERSIST session:user1
# (integer) 1

127.0.0.1:6379> TTL session:user1
# (integer) -1   ← 만료 시간 제거됨

# EXPIRE — 모든 자료형에 적용 가능
127.0.0.1:6379> RPUSH mylist "a" "b" "c"
127.0.0.1:6379> EXPIRE mylist 60
127.0.0.1:6379> TTL mylist
# (integer) 58

127.0.0.1:6379> SADD tags:post:1 "redis" "cache"
127.0.0.1:6379> EXPIRE tags:post:1 86400
127.0.0.1:6379> TTL tags:post:1
# (integer) 86397

127.0.0.1:6379> ZADD ranking:game 9800 "Kim"
127.0.0.1:6379> EXPIRE ranking:game 3600
127.0.0.1:6379> TTL ranking:game
# (integer) 3598

# EXPIRE — 키 전체에 적용 (Hash 필드 단위 불가, Redis 7.4 미만)
127.0.0.1:6379> HSET user:1 name "Kim" age "30"
127.0.0.1:6379> EXPIRE user:1 3600   # user:1 키 전체가 1시간 후 만료
# (integer) 1
```

> ⚠️ `EXPIRE`는 키 전체에 적용됩니다. 필드 단위 TTL은 Redis 7.4+의 `HEXPIRE`를 사용하세요.

## 5. SCAN — 커서 기반 키 순회

```bash
# 전체 키 순회
127.0.0.1:6379> SCAN 0
# 1) "0"           ← 커서 0이면 순회 완료
# 2) 1) "user:1"
#    2) "session:user1"
#    3) "ranking:game"

# 패턴으로 필터링
127.0.0.1:6379> SCAN 0 MATCH user:*
# 1) "0"
# 2) 1) "user:1"

# 자료형으로 필터링
127.0.0.1:6379> SCAN 0 TYPE hash
# 1) "0"
# 2) 1) "user:1"
```

> ⚠️ 운영 환경에서 `KEYS *` 대신 반드시 `SCAN`을 사용하세요.  
> ⚠️ 순회 중 키가 추가·삭제되면 일부 키가 중복 반환되거나 누락될 수 있습니다.
