# Redis Set 명령어 모음

> 강의노트 Ch.03 — Redis 기본 자료형과 명령어 / Set

---

## 1. 기본 명령어

```bash
# SADD — 값 추가
127.0.0.1:6379> SADD tags:post:1 "redis" "database" "cache"
# (integer) 3   ← 새로 추가된 값 수

# 중복 값 추가 시도
127.0.0.1:6379> SADD tags:post:1 "redis"
# (integer) 0   ← 중복이라 추가 안 됨

# SREM — 값 삭제
127.0.0.1:6379> SREM tags:post:1 "cache"
# (integer) 1   ← 삭제된 값 수

# 존재하지 않는 값 삭제 시도
127.0.0.1:6379> SREM tags:post:1 "nosql"
# (integer) 0   ← 존재하지 않아 삭제 안 됨

# SISMEMBER — 값 존재 여부 확인
127.0.0.1:6379> SISMEMBER tags:post:1 "redis"
# (integer) 1   ← 존재함

127.0.0.1:6379> SISMEMBER tags:post:1 "mysql"
# (integer) 0   ← 존재하지 않음

# SMISMEMBER — 여러 값 존재 여부 한번에 확인
127.0.0.1:6379> SMISMEMBER tags:post:1 "redis" "mysql" "database"
# 1) (integer) 1   ← redis 존재
# 2) (integer) 0   ← mysql 없음
# 3) (integer) 1   ← database 존재

# SMEMBERS — 전체 값 조회
127.0.0.1:6379> SMEMBERS tags:post:1
# 1) "redis"
# 2) "database"

# SCARD — 값 개수 확인
127.0.0.1:6379> SCARD tags:post:1
# (integer) 2
```

> ⚠️ `SMEMBERS`는 O(N) 명령어입니다. 값이 많은 경우 `SSCAN`을 사용하세요.

## 2. 랜덤 값 추출

```bash
# 실습 데이터 준비
127.0.0.1:6379> SADD lottery "user:1" "user:2" "user:3" "user:4" "user:5"
# (integer) 5

# SPOP — 임의의 값 꺼내기 (Set에서 삭제됨)
127.0.0.1:6379> SPOP lottery
# "user:3"

# 여러 개 꺼내기
127.0.0.1:6379> SPOP lottery 2
# 1) "user:1"
# 2) "user:5"

# SRANDMEMBER — 임의의 값 조회 (삭제 안 함)
127.0.0.1:6379> SRANDMEMBER lottery
# "user:2"

# 양수: 중복 없이 N개 조회
127.0.0.1:6379> SRANDMEMBER lottery 2
# 1) "user:2"
# 2) "user:4"

# 음수: 중복 허용하여 N개 조회
127.0.0.1:6379> SRANDMEMBER lottery -5
# 1) "user:2"
# 2) "user:2"
# 3) "user:4"
# 4) "user:2"
# 5) "user:4"
```

## 3. 집합 연산 명령어

```bash
# 실습 데이터 준비
127.0.0.1:6379> SADD user:1:follow "user:2" "user:3" "user:4"
127.0.0.1:6379> SADD user:2:follow "user:3" "user:5" "user:6"

# SUNION — 합집합
127.0.0.1:6379> SUNION user:1:follow user:2:follow
# 1) "user:2"
# 2) "user:3"
# 3) "user:4"
# 4) "user:5"
# 5) "user:6"

# SINTER — 교집합
127.0.0.1:6379> SINTER user:1:follow user:2:follow
# 1) "user:3"   ← 공통 팔로우

# SDIFF — 차집합
# user:1이 팔로우하지만 user:2는 팔로우하지 않는 목록
127.0.0.1:6379> SDIFF user:1:follow user:2:follow
# 1) "user:2"
# 2) "user:4"

# SINTERSTORE — 교집합 결과를 새 키에 저장
127.0.0.1:6379> SINTERSTORE common:follow user:1:follow user:2:follow
# (integer) 1   ← 저장된 값 수

127.0.0.1:6379> SMEMBERS common:follow
# 1) "user:3"

# SUNIONSTORE — 합집합 결과를 새 키에 저장
127.0.0.1:6379> SUNIONSTORE all:follow user:1:follow user:2:follow
# (integer) 5

# SDIFFSTORE — 차집합 결과를 새 키에 저장
127.0.0.1:6379> SDIFFSTORE diff:follow user:1:follow user:2:follow
# (integer) 2
```

## 4. SSCAN — 대량 값 조회

```bash
# 커서 0부터 시작
127.0.0.1:6379> SSCAN tags:post:1 0
# 1) "0"           ← 커서 0이면 순회 완료
# 2) 1) "redis"
#    2) "database"

# 패턴으로 필터링
127.0.0.1:6379> SSCAN tags:post:1 0 MATCH r*
# 1) "0"
# 2) 1) "redis"
```

## 5. 실무 활용 예시

```bash
# 태그 시스템
127.0.0.1:6379> SADD tags:post:1 "redis" "database" "cache"
127.0.0.1:6379> SADD tags:post:2 "redis" "nosql" "performance"

# 두 게시글의 공통 태그
127.0.0.1:6379> SINTER tags:post:1 tags:post:2

# 팔로우 / 친구 추천
127.0.0.1:6379> SADD user:1:follow "user:2" "user:3" "user:4"
127.0.0.1:6379> SADD user:2:follow "user:3" "user:5" "user:6"

# 공통 팔로우 (함께 아는 사람)
127.0.0.1:6379> SINTER user:1:follow user:2:follow

# user:1에게 추천할 사람 (user:2가 팔로우하지만 user:1은 아닌 사람)
127.0.0.1:6379> SDIFF user:2:follow user:1:follow

# 좋아요 / 중복 방지
127.0.0.1:6379> SADD likes:post:1 "user:1"
127.0.0.1:6379> SADD likes:post:1 "user:1"   # 중복 → 무시됨
127.0.0.1:6379> SCARD likes:post:1

# 중복 없는 랜덤 추첨
127.0.0.1:6379> SADD event:lottery "user:1" "user:2" "user:3" "user:4" "user:5"
127.0.0.1:6379> SPOP event:lottery 3
```
