## 1. redis-cli로 Pipelining 실습

### commands.txt 파일 준비

```bash
SET pipeline:user:1 "Alice"
SET pipeline:user:2 "Bob"
SET pipeline:user:3 "Charlie"
GET pipeline:user:1
GET pipeline:user:2
GET pipeline:user:3
```

### 파일의 명령어를 Redis에 전달

```bash
docker exec -i my-redis redis-cli < commands.txt
# OK
# OK
# OK
# Alice
# Bob
# Charlie
```

### 결과 확인

```bash
127.0.0.1:6379> MGET pipeline:user:1 pipeline:user:2 pipeline:user:3
# 1) "Alice"
# 2) "Bob"
# 3) "Charlie"
```

### 대량 데이터 고속 로딩 (--pipe 옵션)

```bash
# 수백만 건 이상 데이터 마이그레이션, 초기 데이터 로딩 시 사용
docker exec -i my-redis redis-cli --pipe < commands.txt
```

## 2. Python(redis-py)에서 Pipelining

```python
# transaction=False: 순수 Pipelining 모드 (MULTI/EXEC 없이 전송)
pipe = r.pipeline(transaction=False)
pipe.set("user:1", "Alice")
pipe.set("user:2", "Bob")
pipe.get("user:1")
results = pipe.execute()  # 이 시점에 서버로 한꺼번에 전송
# results → [True, True, 'Alice']
```

### 대량 데이터 분할 전송 (청크 단위 권장)

```python
CHUNK_SIZE = 1000  # 수백~수천 개 단위로 분할

for i in range(0, len(items), CHUNK_SIZE):
    pipe = r.pipeline(transaction=False)
    for key, value in items[i:i + CHUNK_SIZE]:
        pipe.set(key, value)
    pipe.execute()
```

> ⚠️ Pipeline에 명령어를 무한정 쌓으면 Redis Output Buffer 과부하로 연결이 강제 종료될 수 있습니다. 수백~수천 개 단위로 분할 전송하세요.
