# FastAPI 환경 설치 명령어 모음

> 강의노트 Ch.06 — Redis 실무 활용 패턴 / 파이썬 백엔드(FastAPI) 환경 설치

---

## 1. Python 설치 확인

```bash
python --version
# Python 3.14.x
```

---

## 2. 패키지 설치

```bash
pip install fastapi uvicorn redis
```

### 설치 확인

```bash
pip show fastapi uvicorn redis
```

---

## 3. 프로젝트 폴더 생성

```bash
mkdir redis-fastapi
cd redis-fastapi
code .
```

---

## 4. 첫 FastAPI 앱 작성

`main.py` 파일 생성 후 아래 코드 입력:

```python
# FastAPI 동작 확인용 최소 앱
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "FastAPI 환경 설치 완료"}
```

---

## 5. 앱 실행

```bash
python -m uvicorn main:app --reload
# INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
```

### 브라우저 확인

```
http://127.0.0.1:8000/       # 응답 확인
http://127.0.0.1:8000/docs   # Swagger UI 확인
```
