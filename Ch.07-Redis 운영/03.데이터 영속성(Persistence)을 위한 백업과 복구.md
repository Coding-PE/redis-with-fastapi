# Redis 데이터 영속성 (Persistence) — 백업과 복구

> 강의노트 Ch.07 — Redis 운영 / 데이터 영속성을 위한 백업과 복구

---

## 1. RDB — 현재 설정 확인

```bash
# RDB 저장 조건 확인
127.0.0.1:6379> CONFIG GET save
# 1) "save"
# 2) "3600 1 300 100 60 10000"   ← 값이 있으면 활성화, 비어 있으면 비활성화

# 저장 파일명 및 경로 확인
127.0.0.1:6379> CONFIG GET dbfilename
# 1) "dbfilename"
# 2) "dump.rdb"

127.0.0.1:6379> CONFIG GET dir
# 1) "dir"
# 2) "/data"
```

---

## 2. RDB — 수동 저장

```bash
# 동기 저장 — 저장 완료까지 블로킹 (운영 환경 주의)
127.0.0.1:6379> SAVE

# 비동기 저장 — 백그라운드 저장 (권장)
127.0.0.1:6379> BGSAVE
# Background saving started

# 마지막 저장 시각 확인 (Unix 타임스탬프)
127.0.0.1:6379> LASTSAVE
# (integer) 1717200000
```

---

## 3. AOF — 현재 설정 확인

```bash
# AOF 활성화 여부 확인
127.0.0.1:6379> CONFIG GET appendonly
# 1) "appendonly"
# 2) "no"   ← 기본값: 비활성화

# 동기화 정책 확인
127.0.0.1:6379> CONFIG GET appendfsync
# 1) "appendfsync"
# 2) "everysec"

# AOF Auto Rewrite 설정 확인
127.0.0.1:6379> CONFIG GET auto-aof-rewrite-percentage
# 1) "auto-aof-rewrite-percentage"
# 2) "100"

127.0.0.1:6379> CONFIG GET auto-aof-rewrite-min-size
# 1) "auto-aof-rewrite-min-size"
# 2) "67108864"   ← 64MB
```

---

## 4. AOF — 런타임 활성화

```bash
127.0.0.1:6379> CONFIG SET appendonly yes
# OK

# AOF Rewrite 수동 실행
127.0.0.1:6379> BGREWRITEAOF
# Background append only file rewriting started
```

---

## 5. 실습 1 — 영속성 없이 재시작 시 데이터 유실

```bash
# RDB 자동 저장 비활성화
127.0.0.1:6379> CONFIG SET save ""
# OK

# 기존 dump.rdb 파일 삭제
docker exec -it my-redis rm /data/dump.rdb

# 데이터 저장
127.0.0.1:6379> SET persistence:test "hello"
# OK

# Redis 재시작
docker restart my-redis

# 데이터 유실 확인
127.0.0.1:6379> GET persistence:test
# (nil)   ← 데이터 유실
```

---

## 6. 실습 2 — RDB 활성화 후 재시작 시 데이터 복구

```bash
# RDB 활성화
127.0.0.1:6379> CONFIG SET save "3600 1 300 100 60 10000"
# OK

127.0.0.1:6379> SET persistence:test "hello"
# OK

# 수동으로 즉시 스냅샷 저장
127.0.0.1:6379> BGSAVE
# Background saving started

# 저장 완료 확인 (LASTSAVE 값이 변경되면 완료)
127.0.0.1:6379> LASTSAVE
# (integer) 1717200100

# Redis 재시작
docker restart my-redis

# 데이터 복구 확인
127.0.0.1:6379> GET persistence:test
# "hello"   ← 데이터 복구 성공
```

---

## 7. 실습 3 — AOF 활성화 옵션으로 컨테이너 실행

```bash
# 기존 컨테이너 삭제
docker stop my-redis
docker rm my-redis

# AOF 활성화 옵션으로 새 컨테이너 실행
docker run -d --name my-redis -p 127.0.0.1:6379:6379 redis redis-server --appendonly yes

# AOF 활성화 여부 확인
127.0.0.1:6379> CONFIG GET appendonly
# 1) "appendonly"
# 2) "yes"

# 데이터 저장
127.0.0.1:6379> SET aof:test "world"
# OK

# AOF 파일 생성 확인
docker exec -it my-redis ls -lh /data/

# Redis 재시작
docker restart my-redis

# 데이터 복구 확인
127.0.0.1:6379> GET aof:test
# "world"   ← AOF로 복구 성공
```
