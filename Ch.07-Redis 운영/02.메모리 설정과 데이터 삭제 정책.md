# Redis 메모리 설정과 데이터 삭제 정책

> 강의노트 Ch.07 — Redis 운영 / 메모리 설정과 데이터 삭제 정책

---

## 1. maxmemory — 메모리 한도 설정

```bash
# redis.conf
maxmemory 2gb
maxmemory 512mb

# redis-cli에서 런타임 설정
127.0.0.1:6379> CONFIG SET maxmemory 256mb
# OK

# 설정 확인
127.0.0.1:6379> CONFIG GET maxmemory
# 1) "maxmemory"
# 2) "268435456"

# Docker 환경 (호스트에서 실행)
docker exec -it my-redis redis-cli CONFIG SET maxmemory 256mb
```

---

## 2. 현재 메모리 사용량 확인

```bash
127.0.0.1:6379> INFO memory
# used_memory_human:2.50M        ← 현재 사용 중인 메모리
# used_memory_peak_human:3.10M   ← 최대 사용했던 메모리
# maxmemory_human:100.00M        ← 설정된 한도
# maxmemory_policy:noeviction    ← 현재 삭제 정책

# 필요한 항목만 조회
127.0.0.1:6379> CONFIG GET maxmemory
127.0.0.1:6379> CONFIG GET maxmemory-policy
```

---

## 3. Eviction Policy — 데이터 삭제 정책 설정

```bash
# redis.conf
maxmemory-policy allkeys-lru

# redis-cli에서 런타임 설정
127.0.0.1:6379> CONFIG SET maxmemory-policy allkeys-lru
# OK

127.0.0.1:6379> CONFIG GET maxmemory-policy
# 1) "maxmemory-policy"
# 2) "allkeys-lru"
```

---

## 4. noeviction 상태에서 메모리 한도 초과 시

```bash
127.0.0.1:6379> SET key "value"
# (error) OOM command not allowed when used memory > 'maxmemory'
```

---

## 5. 메모리 단편화 확인 및 조치

```bash
# 단편화 비율 확인
127.0.0.1:6379> INFO memory
# mem_fragmentation_ratio:1.5   ← 1.5 이상이면 단편화 가능성

# Active Defragmentation 활성화 (Redis 4.0+, 서비스 중단 없이 점진적 완화)
127.0.0.1:6379> CONFIG SET activedefrag yes
# OK
```

---

## 6. 실무 적용 — 캐시 서버 메모리 정책 변경

```bash
# redis-cli 접속 후
127.0.0.1:6379> INFO memory
127.0.0.1:6379> CONFIG SET maxmemory-policy allkeys-lru
# OK
127.0.0.1:6379> CONFIG GET maxmemory-policy
# 1) "maxmemory-policy"
# 2) "allkeys-lru"

# Docker 환경 (호스트에서 실행)
docker exec -it my-redis redis-cli INFO memory | findstr maxmemory
docker exec -it my-redis redis-cli CONFIG SET maxmemory-policy allkeys-lru
docker exec -it my-redis redis-cli CONFIG GET maxmemory-policy
```
