## 1. KEYS * → SCAN으로 대체

```bash
# ❌ 운영 환경 사용 금지
127.0.0.1:6379> KEYS *

# ✅ SCAN — 커서 기반으로 분할 조회
# cursor 0으로 시작
127.0.0.1:6379> SCAN 0 MATCH user:* COUNT 10
# 1) "48"          ← 다음 커서 (0이 될 때까지 반복)
# 2) 1) "user:1001"
#    2) "user:1002"

# 반환된 커서로 다음 조회
127.0.0.1:6379> SCAN 48 MATCH user:* COUNT 10
# 1) "0"           ← 커서 0 = 전체 순회 완료
# 2) 1) "user:1003"
```

## 2. TTL 없는 키 — 메모리 누수 방지

```bash
# String — SET과 동시에 TTL 설정 (원자적)
127.0.0.1:6379> SET session:1 "user-data" EX 3600
# OK

# Hash / List / Set — EXPIRE 별도 호출
127.0.0.1:6379> HSET user:1 name "Alice"
127.0.0.1:6379> EXPIRE user:1 3600

# TTL 확인
127.0.0.1:6379> TTL session:1
# (integer) 3598   ← 남은 시간(초)

127.0.0.1:6379> TTL user:1001
# (integer) -1     ← TTL 없음 (영구 보관)

# 운영 중 TTL 없는 키 현황 파악
127.0.0.1:6379> INFO keyspace
# db0:keys=10000,expires=8500,avg_ttl=86400000

# Hash 필드 개별 TTL 설정 (Redis 7.4+)
127.0.0.1:6379> HEXPIRE user:1001 3600 FIELDS 1 session_token
```

## 3. Big Key — 분산 및 비동기 삭제

```bash
# ❌ 모든 상품을 하나의 List에 저장
127.0.0.1:6379> LPUSH products "product1" "product2" ... "product100000"

# ✅ 카테고리 단위로 분산
127.0.0.1:6379> LPUSH products:electronics "product1" "product2"
127.0.0.1:6379> LPUSH products:clothing "product3" "product4"

# Big Key 확인 (자료형별 가장 큰 키 1개씩 반환)
docker exec -it my-redis redis-cli --bigkeys

# ❌ 블로킹 삭제
127.0.0.1:6379> DEL big_key

# ✅ 비동기 삭제 (Redis 4.0+)
127.0.0.1:6379> UNLINK big_key
```

## 4. Hot Key — 키 복제 분산

```bash
# 쓰기 — 모든 복제 키에 동일하게 저장
127.0.0.1:6379> SET notice:event:1 "이벤트 시작!"
127.0.0.1:6379> SET notice:event:2 "이벤트 시작!"
127.0.0.1:6379> SET notice:event:3 "이벤트 시작!"

# 읽기 — 랜덤하게 하나를 선택해서 조회
127.0.0.1:6379> GET notice:event:1   # 또는 :2, :3 중 랜덤
```

## 5. 자료형 올바른 선택

```bash
# ❌ 사용자 정보를 String(JSON)으로 저장
127.0.0.1:6379> SET user:1001 '{"name":"Alice","age":30,"email":"alice@example.com"}'

# ✅ Hash로 저장 (필드 단위 수정/조회 가능)
127.0.0.1:6379> HSET user:1001 name "Alice" age 30 email "alice@example.com"

# 특정 필드만 수정
127.0.0.1:6379> HSET user:1001 age 31
```

## 6. Connection Pool — FastAPI lifespan 패턴

```python
# ❌ 요청마다 새 연결 생성
@app.get("/user/{user_id}")
async def get_user(user_id: str):
    r = redis.Redis(host='localhost', port=6379)  # 매번 새 연결
    return r.get(f"user:{user_id}")
```

```python
# ✅ lifespan으로 Connection Pool 관리
from contextlib import asynccontextmanager
from fastapi import FastAPI, Request
import redis.asyncio as redis

@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.redis = redis.from_url(
        "redis://localhost:6379/0",
        decode_responses=True
    )
    yield
    await app.state.redis.aclose()

app = FastAPI(lifespan=lifespan)

@app.get("/user/{user_id}")
async def get_user(user_id: str, request: Request):
    r = request.app.state.redis  # Pool에서 연결 재사용
    return await r.get(f"user:{user_id}")
```

## 7. 운영 환경 위험 명령어 비활성화

```bash
# redis.conf — 위험 명령어 비활성화 (Redis 6 미만)
rename-command KEYS     ""
rename-command FLUSHDB  ""
rename-command FLUSHALL ""
```

> Redis 6 이상에서는 ACL 기반 권한 제어 권장
